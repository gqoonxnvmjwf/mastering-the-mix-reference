## Overview

Mastering The Mix REFERENCE allows A/B comparison of your mix against reference tracks with loudness-matched playback and spectrum comparison for professional mix decisions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Mastering The Mix REFERENCE** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **A/B Reference** | Instant toggle between your mix and reference tracks |
| **Loudness Match** | Automatic loudness level matching for unbiased comparison |
| **Spectrum Compare** | Overlay your mix spectrum against the reference for EQ guidance |
| **Dynamic Compare** | Side-by-side dynamic range and transient comparison displays |
